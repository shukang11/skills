## TDD 机制设计与单人开发适配

`tdd` 技能将 Matt Pocock 原版的核心红绿循环与反模式防护（反过度 Mock、反同义反复断言）完整吸收。

### 针对个人开发体验的关键适配：里程碑触发原则

在传统团队或教条 TDD 中，要求哪怕改一行代码都必须跑一遍测试运行器。但在单人 + AI 开发的真实体验中，这会导致严重的效率瓶颈：
- AI 动不动就调用测试命令，等待耗时、产生大量命令行输出噪音；
- 上下文窗口被冗余的测试日志快速撑满；
- 频繁打断思路。

因此，在本技能的定制中明确焊死一条铁律：
**“在开发过程当中，除非到达关键里程碑节点（例如完成了一个独立模块、一个可独立验证的完整用户故事），或者用户明确指示执行测试，否则 Agent 不要擅自主动频繁地触发测试。”**

让编码过程保持流畅和专注，只在验收关口实施严格把关。
