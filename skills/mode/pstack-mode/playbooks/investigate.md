# Investigate

Answer the question only. No code changes.

1. Read `how-it-works` for how it works now, where it lives, or which layer it belongs in.
2. Read `why-this-way` for why it looks like this and what trade-off was made. Read both when both questions are live.

When the user moves from answering to changing code, switch to [feature.md](feature.md), [bug-fix.md](bug-fix.md), or [design.md](design.md), and say that you switched.

Done when: every mechanism sentence points at a file you read, and every motive sentence is labelled as from a commit, from a note, or inferred.
