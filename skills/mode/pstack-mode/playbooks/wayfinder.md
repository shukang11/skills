# Wayfinder

More than one session can hold, and the route is still unclear. This playbook writes no implementation.

1. Read `wayfinder`.
2. No `handoff/wayfinder/<slug>/map.md` yet: chart the map by that skill, then stop.
3. Map exists: claim one frontier ticket. For `grilling`, read `grilling` and `domain-modeling`. For `prototype`, read `prototype`. For `research` and `task`, finish that ticket by `wayfinder`'s criteria.
4. No frontier ticket left: stop at the `map.md` path. The next step is [design.md](design.md), starting from `to-spec`, with the settled interviews skipped.

Done when: the map path is in the reply. A charting session lists the frontier ticket titles. A working session names the ticket it resolved and either the next frontier ticket or the fact that the map is clear.
