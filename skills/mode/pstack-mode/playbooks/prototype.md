# Prototype

A faithful simulation of product logic or interaction.

1. Read `prototype`. When the logic or interaction cannot be clicked through yet, write it as one sentence you can walk on a page before creating files.
2. When two or more structural options remain, read `compare-shapes` first. Skip when the shape is already unique.
3. The simulation stays in `prototypes/`. A contract worth keeping goes into the matching `docs/` topic, then switch to [design.md](design.md) or [feature.md](feature.md). Simulation files never become production code.

Done when: the reply carries the entry path `prototypes/index.html` and the piece of logic or interaction that now walks on the page.
