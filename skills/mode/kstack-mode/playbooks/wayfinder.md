# Wayfinder

一次会话装不下，而且路线还看不清。本 playbook 不写实现。

1. 读 `wayfinder`。
2. 还没有 `handoff/wayfinder/<slug>/map.md`：按该技能画图，写完即停。
3. 已有地图：认领一张前沿票。`grilling` 再读 `clarify-decisions` 和 `domain-modeling`。`prototype` 再读 `prototype`。`research` 和 `task` 按 `wayfinder` 的判据做完这一张。
4. 地图没有前沿票：停在 `map.md` 路径。下一步改走 [design.md](design.md)，从 `to-spec` 起，已完成的盘问 skip。

收工：回复里有地图路径。画图时列出前沿票标题。做票时写明解开的是哪一张，以及下一张前沿票或地图已清空。
