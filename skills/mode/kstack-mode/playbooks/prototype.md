# Prototype

做一套保真的产品逻辑或交互模拟。

1. 读 `prototype`。要看清的逻辑或交互还不能点出来时，先写成一句能在页面上走通的话，再创建文件。
2. 结构上还有两种以上方案时，先读 `compare-shapes`。方案已经唯一则 skip。
3. 模拟留在 `prototypes/`。确认要留下的契约写进 `docs/` 对应 topic，再改走 [design.md](design.md) 或 [feature.md](feature.md)。不把模拟文件当成生产代码。

收工：回复里有入口路径 `prototypes/index.html`，以及页面上走通的那段逻辑或交互。
